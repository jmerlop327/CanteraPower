# Constitución de CanteraPower

1. Stack mínimo: HTML, CSS y JavaScript sin frameworks ni librerías externas.
2. La spec manda: el código debe cumplir lo descrito en los documentos del proyecto.
3. Lógica e interfaz separadas: la lógica de negocio no depende de la UI.
4. Tests obligatorios para cualquier funcionalidad nueva antes de mergear.
5. Código y textos en español, sin excepciones.
